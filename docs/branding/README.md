# Branding — Caderno D’Vinho

Esta pasta reúne os materiais de identidade visual da marca Caderno D’Vinho.

## Conteúdo
- Brand board
- Logos principais e alternativas
- Favicon
- Paleta de cores
- Tipografia
- Elementos visuais de apoio
- Mockups de aplicação da marca

## Objetivo
Documentar como a identidade visual foi construída e demonstrar aplicações práticas da marca em canais digitais, redes sociais e peças de comunicação.
